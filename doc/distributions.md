| :------------------ | :---------------------------------------------------------------------------------------------------------- | :---------------------------------------------------- | :-------------------------------------------------------------------------------------- | :---------------------------- | :----------------------------------------------------- |
| **Bernoulli**       | $p^k(1-p)^{1-k}$                                                                                            | Un singur experiment cu succes/eșec.                  | $(p, \text{"pe"}, \text{probabilitatea de succes})$                                     | $p$                           | $p(1-p)$                                               |
| **Binomială**       | $\binom{n}{k} p^k (1-p)^{n-k}$                                                                              | Numărul de succese în $n$ încercări.                  | $(n, \text{"en"}, \text{număr încercări}), (p, \text{"pe"}, \text{prob. succes})$       | $np$                          | $np(1-p)$                                              |
| **Geometrică**      | $(1-p)^{k-1}p$                                                                                              | Numărul de încercări până la primul succes.           | $(p, \text{"pe"}, \text{probabilitatea de succes})$                                     | $\frac{1}{p}$                 | $\frac{1-p}{p^2}$                                      |
| **Poisson**         | $\frac{\lambda^k e^{-\lambda}}{k!}$                                                                         | Numărul de evenimente într-un interval fix.           | $(\lambda, \text{"lambda"}, \text{rata medie de apariție})$                             | $\lambda$                     | $\lambda$                                              |
| **Uniformă**        | $\frac{1}{b-a}$                                                                                             | Probabilitate constantă pe un interval $[a, b]$.      | $(a, \text{"a"}, \text{limita inf.}), (b, \text{"be"}, \text{limita sup.})$             | $\frac{a+b}{2}$               | $\frac{(b-a)^2}{12}$                                   |
|                     |                                                                                                             |                                                       |                                                                                         |                               |                                                        |
| **Normală**         | $\frac{1}{\sigma\sqrt{2\pi}} e^{-\frac{1}{2}\left(\frac{x-\mu}{\sigma}\right)^2}$                           | Modelarea fenomenelor naturale; "Clopotul lui Gauss". | $(\mu, \text{"miu"}, \text{media}), (\sigma, \text{"sigma"}, \text{abaterea standard})$ | $\mu$                         | $\sigma^2$                                             |
| **Exponențială**    | $\lambda e^{-\lambda x}$                                                                                    | Timpul de așteptare între evenimente.                 | $(\lambda, \text{"lambda"}, \text{rata de intensitate})$                                | $\frac{1}{\lambda}$           | $\frac{1}{\lambda^2}$                                  |
| **Beta**            | $\frac{x^{\alpha-1}(1-x)^{\beta-1}}{B(\alpha, \beta)}$                                                      | Modelarea incertitudinii unei probabilități.          | $(\alpha, \text{"alfa"}, \text{formă 1}), (\beta, \text{"beta"}, \text{formă 2})$       | $\frac{\alpha}{\alpha+\beta}$ | $\frac{\alpha\beta}{(\alpha+\beta)^2(\alpha+\beta+1)}$ |
| **Gamma**           | $\frac{1}{\Gamma(k)\theta^k} x^{k-1} e^{-\frac{x}{\theta}}$                                                 | Timpul până la al $k$-lea eveniment Poisson.          | $(k, \text{"ca"}, \text{formă}), $(\theta, \text{"teta"}, \text{scară})$                | $k\theta$                     | $k\theta^2$                                            |
| **t-Student**       | $\frac{\Gamma(\frac{\nu+1}{2})}{\sqrt{\nu\pi}\Gamma(\frac{\nu}{2})} (1+\frac{x^2}{\nu})^{-\frac{\nu+1}{2}}$ | Estimări pe eșantioane mici cu varianță necunoscută.  | $(\nu, \text{"niu"}, \text{grade de libertate})$                                        | $0$ (pt $\nu > 1$)            | $\frac{\nu}{\nu-2}$ (pt $\nu > 2$)                     |
